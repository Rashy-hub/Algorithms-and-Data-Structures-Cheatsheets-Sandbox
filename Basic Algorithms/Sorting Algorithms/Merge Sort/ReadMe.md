# Merge Sort Algorithm

## Introduction

**Merge Sort** is a divide-and-conquer algorithm that was invented by John von Neumann in 1945. It divides the input array into two halves, sorts each half, and then merges the two sorted halves back together.

## How It Works

1. Divide the unsorted array into two halves.
2. Recursively sort both halves.
3. Merge the sorted halves to produce the sorted array.

## Time and Space Complexity

-   **Best Case Time Complexity**: O(n log n)
-   **Average Case Time Complexity**: O(n log n)
-   **Worst Case Time Complexity**: O(n log n)
-   **Space Complexity**: O(n) - Requires additional space for merging.
